**Self-contained `CreateProductPanel` component (name / base price (€) / category + shared `VariantGenerator`) that creates a product and its opening stock in one `POST /api/products` call, surfacing 409 SKU clashes inline without losing typed input.**

## Accomplishments
- Built the D-12 minimal create form (Name, Base price (€), Category) rendering the shared `VariantGenerator` for size x colour variant generation, with Checkout.tsx-style validate-on-blur and an inline-derived `canSubmit`
- Wired submission to `createProduct` from `web/src/lib/inventory.ts`, sending `variants[].stock` in the same create call (D-11) and always `priceAdjustment: 0` (D-20)
- Implemented the full success/failure contract: success clears the form and remounts the generator via a `generatorKey` bump; a 409/other `Error` renders verbatim in a `role="alert"` element with every typed value intact; `AuthExpiredError` routes straight to `props.onAuthExpired` (D-30)
- Covered all of the above plus the pending "Creating…" state and the D-10/D-12/D-20 negative assertion (no description/image/price-adjustment control) in 8 new Vitest/RTL tests, with the full web suite green at 193/193 (up from the 185 baseline + this plan's 8)
