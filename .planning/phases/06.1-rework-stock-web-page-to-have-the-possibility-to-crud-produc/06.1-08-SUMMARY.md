## Decisions Made
- Task 1 introduces an interim `p.active` filter (no toggle UI yet) so the shell never renders archived products unlabeled before Task 2 adds the real toggle — this was necessary to keep the page's behavior coherent between task-level commits, since the plan explicitly defers the toggle state to Task 2.
- `vite-react-ssg`'s `Head` renders `react-helmet-async`'s `Helmet`, which requires a `HelmetProvider` ancestor (supplied at runtime only by `ViteReactSSG()` in `main.tsx`). Rendering `<Stock />` standalone in RTL has no such provider and `Helmet` throws without one, so per the plan's documented fallback, `vite-react-ssg` is mocked in the test file to stub `Head` as a pass-through, and the `noindex` meta is asserted directly via `document.querySelector`. The real build was independently verified to emit `noindex` correctly (see Self-Check).
- Product-name header row upgraded to the Heading role (`font-display text-xl uppercase`) per UI-SPEC's explicitly prescribed, non-scope-creep typography change from the prior `font-sans font-bold`.
